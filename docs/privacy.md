# Privacy

EvidenceWeave's core workspace is local-first. Notes created in the current foundation are stored in the browser's IndexedDB. The application has no login requirement, analytics SDK, server-side document database, or model API integration.

Users control explicit export files. Clearing site data or the browser profile can remove local data, so portable exports are the current backup mechanism.

Future optional integrations must be opt-in and must state exactly what data leaves the device before transmission.
